Design Spec & Handoff

A "Dabang"-flavoured restyle for your Streamlit data-lakehouse dashboard — rounded white cards on a lavender canvas, a single purple primary, pastel metric tiles and muted charts. Everything below drops into app.py without leaving Streamlit. ↗ Open the Exploitation mockup

Note on the brief: you originally asked for a serif / navy / terracotta "academic observatory" look. This handoff follows your later instruction to match the Dabang reference instead — friendly geometric sans, purple accent, pastel tiles. The data, 6-zone structure and Streamlit-only constraint are untouched. Say the word if you want the serif direction back.

05Streamlit code patterns

Five reusable moves. The rule of thumb: Streamlit primitive for the data, a thin HTML wrapper for the chrome.

pattern 1Figure card = bordered container + HTML inner

Loop dim_figure rows into st.columns(3). In each cell use with st.container(border=True): then a single st.markdown(card_html, unsafe_allow_html=True) holding the .portrait, name, .chiplet tags, bio and small-caps links. Do render the portrait as a tinted monogram div; don't use st.metric here.

pattern 2Metric tile, not st.metric

The pastel tile + icon chip is custom: st.columns(4), each a st.markdown with div.metric-tile.lilac/mint/peach/pink. Keeps the big Poppins number, the green delta line and the saturated icon chip that plain st.metric can't produce.

pattern 3Charts via Altair theme, one hue each

Register a muted theme once, then st.altair_chart(alt.Chart(df).mark_bar(color="#8C7CF8", cornerRadius=6)…, use_container_width=True). Hide the grid and lighten axes so whitespace carries the layout. One hue per chart — never a rainbow.

pattern 4SQL console = text_area + button + dataframe

q = st.text_area("", value=DEFAULT_SQL, height=150) styled by .stTextArea textarea (dark, mono). st.button("Run query", type="primary") → con.execute(q).df() into st.dataframe(..., use_container_width=True). Guard it read-only (reject anything but SELECT).

pattern 5Connection block in the sidebar

One st.sidebar.code(conn_text, language="bash") — the section[data-testid="stSidebar"] .stCode rule turns it into the fixed dark monospaced panel. Pair with a green status dot via a small st.markdown above it.
